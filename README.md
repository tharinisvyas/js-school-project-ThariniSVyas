# 🌌 Memory Constellation – Task 3: Interactivity with JavaScript

An enhanced version of the **Memory Constellation** website that introduces dynamic interactivity using **vanilla JavaScript**.  
This stage focuses on **loading events from a JSON file, rendering them dynamically, and enabling interactive modals**.

---

## 🎯 Project Goal

To make the timeline **fully interactive** by:

- Dynamically fetching and displaying memories from an external `events.json` file.
- Grouping events by year and displaying them in a visually appealing layout.
- Allowing users to click on any memory card to view **full details in a modal popup**.
- Implementing a **close functionality** for the modal for a smooth user experience.
- Preserving the **theme toggle feature** while keeping all elements accessible and responsive.

---

## 🛠 Features Implemented in Task 3

- **Dynamic Content Loading** – All events are loaded from `events.json` using the `fetch()` API.
- **Year Grouping** – Events are displayed under their respective year headings.
- **Interactive Modals** – Clicking a memory card opens a modal with:
  - Large image
  - Event title & description
- **Close Button & Overlay Click** – Modal can be closed by clicking the ❌ button or outside the modal.
- **Theme Toggle Support** – Works seamlessly with dark and light galaxy backgrounds.
- **Accessible Keyboard Navigation** – Modal can be closed with the `Esc` key.
