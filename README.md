# 🌌 Memory Constellation - CSS Styling

A responsive and visually captivating personal timeline website showcasing cherished memories. This stage focuses on **styling with CSS** to bring the HTML structure to life.

---

## 🎯 Project Goal

To create an **interactive, accessible, and mobile-friendly timeline** that:

* Visually narrates personal milestones with images, captions, and descriptions.
* Uses **responsive design** with Flexbox and CSS Grid for seamless adaptation to desktop, tablet, and mobile.
* Provides a **theme toggle button** to switch between two galaxy-inspired backgrounds.
* Enhances user experience with hover effects, soft shadows, and a polished space-themed aesthetic.

---

## 🛠 Features Implemented in Task 2

* **Responsive Layout** — CSS Grid for flexible resizing across devices.
* **Space-Inspired Backgrounds** — Two galaxy-themed radial gradients.
* **Theme Toggle** — Switch between background styles with one click.
* **Card Styling** — Semi-transparent backgrounds with hover lift effects.
* **Accessibility Enhancements** — High contrast, clear typography, and semantic structure.

---

## 🚀 Initial Roadmap

**Phase 1 — Structure & Styling (Task 1 & Task 2)** ✅

* Build semantic HTML structure for memory entries.

* Apply galaxy-inspired background styles.
* Add theme toggle functionality.

**Phase 2 — Interactivity (Task 3 & Task 4)** 🔄

**Phase 3 — Advanced Enhancements (Task 5 & Task 6)** ⏳
