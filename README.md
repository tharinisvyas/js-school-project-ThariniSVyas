# Exclusive HTML Task - Memory Constellation

Welcome to the **HTML Task** for the Web Development course by Data Art School! This is **Task I** of our interactive project: **Memory Constellation**.

## 📁 Project Overview

**Memory Constellation** is a unique timeline web app that allows users to visualize life memories as constellations in a starry sky. The goal is to creatively display important moments as floating stars connected in chronological order, offering an immersive storytelling experience.

This task lays the **foundation** of the project using **pure HTML only**.

---

## 🔄 Task Flow

This project will be built in 6 tasks:

1. **HTML Structure** *(Current task)*
2. CSS Styling
3. JavaScript Interactivity
4. Responsive Design
5. User Input and Form Handling
6. Final Polishing and Deployment

---

## ✍️ Task I: HTML Skeleton
 the **HTML skeleton** of the Memory Constellation app. Focus purely on structure, semantics, and organization.

### HTML Elements:

* `<!DOCTYPE html>` declaration
* Semantic tags: `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`
* Proper use of `<h1>` to `<h3>` tags
* An image (placeholder for background/stars)
* An unordered list or `<div>`s for memory stars
* A form input to later add memories (e.g., input + submit button)
